欢迎来到我的博客！🎉

这是我用 [Hugo](https://gohugo.io/) 搭建的个人博客，通过 GitHub Actions 自动部署到 GitHub Pages。

## 为什么选择 Hugo？

- ⚡ 极快的构建速度
- 📝 使用 Markdown 写作，简单直观
- 🎨 丰富的主题可选
- 🆓 完全免费，可以托管在 GitHub Pages 上

## 如何写新文章？

只需在 `content/posts/` 目录下新建一个 `.md` 文件，写好内容后 `git push`，GitHub Actions 就会自动构建并部署！

```bash
# 本地新建文章（需要安装 Hugo）
hugo new content posts/my-new-post.md
```

或者直接在 `content/posts/` 目录下创建 Markdown 文件即可。
